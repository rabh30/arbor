# Arbor

**Arbor: An app by Saurabh.** Seven small apps for Windows that sort, de-duplicate, shrink and tidy your photos, videos and files. Nothing is deleted without your say.

- **Media Sorter**: photos and videos into folders by date, copied or moved.
- **Duplicate Reviewer**: identical files, look-alike and similar photos, and an optional on-device AI "Same subject" check.
- **File Sorter**: every file into a folder per type.
- **Space Finder**: what's using your disk, the biggest files, and old stuff by your own time span (not opened, not changed, or made).
- **Image Resizer**: makes photos smaller and converts them: JPG, PNG, WebP, AVIF, TIFF or BMP. HEIC photos can be read and saved in any of these.
- **Video Optimiser**: shrinks or converts every video in a folder. MP4, MKV, MOV or WebM; HEVC, H.264, AV1 or VP9. Your graphics chip does the work, and nothing is made bigger.
- **Empty Folder Remover**: clears out folders with nothing in them.

## Good to know

- **Right-click in File Explorer.** Right-click a folder, a drive, photos or videos, choose **Arbor** and pick a tool: it opens with that already chosen. On Windows 11 it is under **Show more options** (or hold Shift while you right-click). You can switch it off in Settings → Explorer menu.
- **You review before anything changes.** Every tool shows what it will do first.
- **Originals are safe.** Things you remove go to the Recycle Bin. Photos and videos replaced in place keep their originals in a folder beside them, and can be put back.
- **Arbor remembers your choices**: folders, options, looks and the window's size are there the next time you open it.
- **Everything stays on your PC.**

## Install

1. Download `Arbor-<version>-Setup.exe` from the latest release on the [Releases](../../releases/latest) page.
2. Run it. If Windows says "Windows protected your PC", choose **More info → Run anyway**.
3. Open Arbor from the Start menu.

No admin needed. To remove it: Settings → Apps → Arbor → Uninstall (your settings are kept, and Arbor leaves Explorer's menu).

Already have Arbor 1.0.12 or later? Update from inside the app: Settings → Updates and about → Check now.

Prefer no installer? Download `Arbor-<version>-win-x64.zip` instead, unzip it anywhere and run `Arbor.exe`.

Windows 10 or 11, 64-bit. Arbor checks this page for new versions (you can turn that off in Settings); it sends nothing about you or your files.

Video Optimiser uses [FFmpeg](https://ffmpeg.org) (LGPL build), included in the `Tools\ffmpeg` folder with its licence.

This repository holds the downloads only.
